# 계산기 UI/UX 업데이트

- 대출금액: 1,000,000원 단위 증가/감소, 천 단위 쉼표 표시
- 연 이율: 직접 입력 + 0.1% 증가/감소
- 대출기간: 자유 입력 + 증가/감소 + 년/개월 단위 선택
- 거치기간: 자유 입력 + 증가/감소 + 개월 단위
- 상환방식: 원리금균등 / 원금균등 / 만기일시 라디오 선택
- 결과: 총 대출원금 / 총 상환원금 / 총 이자 / 첫 회차
- 월별 상환 스케줄: 기본 12회, 전체 보기
- 초기화 / 결과 복사 제공
- 예금/적금: 하나의 화면에서 거치식 예금 / 적립식 적금 전환
- 예금/적금 연 이율: 직접 입력 + 증가/감소
- 예금/적금 기간: 자유 입력 + 개월/년 선택
- 과세: 일반 과세 / 비과세 / 세금 우대
- 월급/시급: 하나의 화면에서 월급 계산 / 시급 계산 전환
- 일반 CSS 파일 추가 없이 UnoCSS utility/shortcut만 사용
